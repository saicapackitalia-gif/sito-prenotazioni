Configurazione Supabase
Prima configurazione — operazione unica
1
Vai su supabase.com, crea un account e un nuovo progetto (regione: Frankfurt).
2
In Authentication → Providers, assicurati che Email sia abilitato (è attivo di default). Disabilita "Confirm email" se vuoi accesso immediato senza verifica.
3
Vai su SQL Editor ed esegui questo script per creare la tabella prenotazioni:
CREATE TABLE prenotazioni ( id uuid DEFAULT gen_random_uuid() PRIMARY KEY, user_id uuid REFERENCES auth.users(id) ON DELETE CASCADE, vehicle_id text NOT NULL, data date NOT NULL, slot_index integer NOT NULL, nome text NOT NULL, destinazione text NOT NULL, targa text NOT NULL, created_at timestamptz DEFAULT now(), UNIQUE(vehicle_id, data, slot_index) ); ALTER TABLE prenotazioni ENABLE ROW LEVEL SECURITY; -- Tutti possono vedere le prenotazioni CREATE POLICY "select_all" ON prenotazioni FOR SELECT USING (true); -- Solo l'utente loggato può inserire le proprie CREATE POLICY "insert_own" ON prenotazioni FOR INSERT WITH CHECK (auth.uid() = user_id); -- Solo l'utente loggato può cancellare le proprie CREATE POLICY "delete_own" ON prenotazioni FOR DELETE USING (auth.uid() = user_id);
4
Vai su Project Settings → API e copia Project URL e anon public key.
